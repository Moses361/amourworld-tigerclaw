# Amourworld Tigerclaw — Master Project Plan

## Project goal
Build a modern, professional, responsive website for Amourworld Tigerclaw, retaining its gold, white and charcoal branding.

## Confirmed technology
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Git and GitHub

## Website scope
- Home
- About
- Services overview and individual service pages
- Clients and industries served
- Contact and quote requests
- Privacy and terms pages as appropriate

## Admin and enquiry requirements
- Secure admin login and dashboard
- Manage enquiries, services and website content
- Validate and store enquiries
- Email notifications
- WhatsApp contact option
- Database and authentication choices to be finalized before implementation

## Quality requirements
- Mobile-first responsive design
- Accessibility and performance
- SEO metadata, sitemap and robots configuration
- Secure handling of forms and administrator access
- Test and verify before deployment

## Hosting
Vercel with a suitable managed PostgreSQL provider is the initial recommendation.
Confirm cost, database and deployment requirements before setup.
